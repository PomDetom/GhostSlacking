# 实验性 Reveal 后台交互

默认关闭的实验功能：在 Reveal 中操作目标 B，同时保留前台 A 的焦点，取消 Reveal 后回到 A。已选定并接入目标线程内独占输入桥接；常规构建和安装包携带交互组件，启用设置即可使用，无需专用构建、额外下载或启动参数。具体机制见[技术路线状态](../architecture/REVEAL_INPUT.md#技术路线状态)。

启用后会向所选目标加载交互组件，兼容性因应用而异。仅随附组件不会自动注入；只有显式开启后台交互并开始会话才加载。实际兼容性及未验证范围只维护在[质量边界](../quality/KNOWN_LIMITATIONS.md)，本功能不保证各类程序通用兼容或网站无法检测切屏。

## 开启与操作

1. 从旧副本托盘恢复全部窗口并退出，再启动所要测试的版本，不同时运行多个副本。
2. 设置 → 实验性功能，开启“后台交互”。“显示”页将 Peek 设为“按下切换”，建议 F8 等独立按键，避免与交互快捷键组成键冲突。
3. 自动开始：开启“持续交互”并保存。手动开始：保持持续选项关闭，配置交互快捷键，先显示 Reveal 再按该键。
4. A 打开[焦点诊断页](../../tools/background-focus-probe.html)并保持前台；选择无敏感内容的目标 B，隐藏 B，把光标移回其原范围后 Peek。
5. 若提示“先点前台”，B 继续隐藏且尚未拦截输入。点击 A 后把光标移回 B 会自动继续；有效前台满足且原按键释放后才准备并显示“交互中”。准备期间新输入被消费，不会延迟重放。
6. 持续模式中移出 B 正常结束，未关闭 Peek 时返回可重新准备。再次 Peek 关闭；交互快捷键结束并收起本次 Reveal，持续选项保持开启。
7. 真实失焦、目标失效、投递失败或未管理弹窗会收起并取消显示意图；必须重新手动 Peek，不循环重试。未支持操作只消费并提示，不等于已成功执行。
8. 设置、选窗、恢复和退出都会取消等待/准备/交互。“请先恢复”表示清理失败，应恢复当前或全部窗口。

持续模式只支持 Toggle Peek，持续 + 按住显示无法保存；外部写入该异常组合也会阻止 Reveal，不退回普通点击。关闭实验总开关保留持续选项但不生效，两项默认均关闭。

## 当前能力与限制

| 操作 | 当前边界 |
| --- | --- |
| 鼠标 | 点击、双击、拖选与连续悬停经过目标正常消息循环；系统光标仍驱动 Reveal 跟随。 |
| 英文输入 | 使用 US 英文路径，不切换 A 的系统布局；结果由目标自己的消息循环处理。 |
| 复制/粘贴 | Ctrl+A/C/V 等编辑快捷键交给目标处理，不依赖编辑器专用命令；桥接组件本身不读写剪贴板。 |
| 菜单 | 支持已验证归属的同线程 Chrome/Electron Views 菜单及子菜单，共用 Reveal 裁剪；原生系统菜单、文件对话框与其他 UI 线程未纳入。 |
| 中文组合输入 | 尚未支持；IME、死键和部分系统组合被消费并提示受限，不转给 A。 |
| 清理 | 停止取消菜单，丢弃未执行输入，仅释放已投递的按下状态；保留准备前属于 A 的抬起，恢复开始后不再追加隐藏。 |
| 权限/隐私 | 只向已验证的 x64 目标 UI 线程加载组件，不默认提权；不抓屏或记录正文、输入及剪贴板。不确定操作不重试。 |
| 组件不可用 | DLL 缺失、损坏或 ABI 不匹配会拒绝开始交互并提示修复安装；不会回退到另一条路线重复操作。 |

HUD 短提示表示会话/能力状态，不是焦点验证结果。“准备交互”表示尚在准备，IME 或系统组合受限表示该操作未执行，“失焦收起”表示检测到前台变化。“交互组件不可用”表示需要修复安装。工具不会自动发送聊天消息。

独占输入支持符合归属校验的 Chrome/Electron 菜单点击、悬停和子菜单；菜单只在随鼠标移动的 Reveal 范围内显示，浮层保持在菜单上方，菜单伸出主窗口时仍保留本次会话。无需先点击才更新光标。Esc 可关闭菜单，取消 Reveal 会取消菜单并清理按下状态；菜单执行命令后正常关闭不会被当成根目标被替换。原生系统菜单、文件对话框及其他 UI 线程不在该支持范围；不能将某个菜单能弹出视为可操作。详见[桥接与菜单机制](../architecture/REVEAL_INPUT.md#原生桥接与菜单)。

## 验收与研究入口

[后台交互验收矩阵](../quality/WINDOWS_MANUAL_MATRIX.md#实验性后台交互)列出首次启动、持续模式、鼠标/文本、保护条件和停止清理步骤。通过必须同时满足 B 操作正确、A 完整焦点记录正常和结束清理正常；最后切回 A 不足以证明全程未失焦。

- [独立控件/Chromium 探测工具](../../tools/BackgroundInteractionProbe/README.md)：UIA、原生 Edit、MSAA 和隔离 CDP，限定在自己的测试窗口/隔离浏览器，不自动连接真实目标。
- [中文输入研究原型](../../tools/BackgroundImeProbe/README.md)：系统 TSF 与独立小词表，未接入正式输入路径，生产可用性未验收。
