# 第六轮：通知自适应宽度与 ChatGPT 粘贴说明

日期：2026-11-02。交付目录 `artifacts/background-interaction-round6/`；前五轮和第四轮中文研究原型保留。

## ChatGPT 无法粘贴的原因

用户反馈第五轮交互不再失败，但 ChatGPT 无法粘贴。15:09:10 日志记录：`adapter=UIAutomationText capabilities=Locate, Drag, Copy rejection=PasteUnavailable`，随后为 `BackgroundInputRejected reason=PasteUnavailable`。代码在 Ctrl+V 分支明确拒绝，没有调用目标的粘贴操作；这与此前 UIA 超时不同。

当前通用 UIA 路径使用 TextPattern 完成定位、选区和读取选区复制，没有已验证的光标插入接口。[微软文档](https://learn.microsoft.com/en-us/dotnet/framework/ui-automation/ui-automation-textpattern-overview)说明 TextPattern 的正文接口不提供修改现有文本的能力。Notepad++ 和 Edit/RichEdit 使用专用原生命令，其粘贴适配不能直接推广到 ChatGPT。进一步支持需单独验证写入路径，本轮保留限制，不向 Chromium 根窗口补发 Ctrl+V、不激活 B，也不整字段覆盖。

第五轮“不再失败”的反馈只作为用户观察记录，不代替逐项操作结果或 A 全程焦点证据。

## 通知行为

- 默认按文字自适应。设置改为“最大宽度 / Maximum width”，中文说明为“通知随内容调整，不超过此宽度”。旧保存值直接作为上限，仍为 100–300 DIP，默认 132。
- 自然宽度使用默认 13 DIP 字号测量，加上边框、左右各 10 DIP 内边距、18 DIP 图标和 9 DIP 间距。最小宽度为 64 DIP 与实际高度中的较大值，再由配置上限和屏幕可用空间约束；短通知可以小于 100 DIP。
- 达到上限后沿用最低 11 DIP 的缩字、短提示收字距和一般长消息单行省略。图文整体居中，高度和圆角仍按配置。
- 先更新文字，再计算尺寸和定位。居中保持居中，左右端点保留原边距；运行时、持续交互 HUD 和设置预览使用同一测量及布局。内容、主题、字体、设置和 DPI 变化时重新测量，定时位置检查复用缓存。
- 沿用淡入淡出，不新增宽度动画；通知优先级、持续时间、悬停暂停、单次点击、鼠标穿透及不激活保障不变。

配置 schema 仍为 10，没有新增字段或开关，不改变完整快照和 Watchdog 协议。

## 编译与验收状态

主程序及 Core/App 测试项目 Release 编译均成功，零警告、零错误；未执行用例或真实窗口自动化。回归源码包含短文字收缩、长文字封顶、64 DIP/高度下限、窄屏约束、左中右锚定、多 DPI、主题切换、设置预览一致及旧配置往返。实际视觉效果和焦点行为仍待用户确认。

## 用户操作

1. 从旧程序托盘恢复全部窗口并退出，启动 `artifacts/background-interaction-round6/GhostSlacking.App.exe`。
2. 常规设置中检查“最大宽度”，原数值应保留。分别设置 100、132、300 DIP，查看预览；修改、取消、保存及重启后数值应正确。
3. 检查“交互中 / Active”等短提示明显收窄；长提示到达上限后适当缩字或省略，关键交互状态完整。连续替换短长提示，不闪现旧宽度，不新增伸缩动画。
4. 检查高度 32/44/96 DIP、圆角、左/中/右和上下位置，中英文及浅深主题；特别确认短通知小于 100 DIP 时图文间距和留白均衡。
5. 在 100%/125%/150%/200% 和混合 DPI 显示器检查尺寸与定位，不超出工作区。比较预览、普通通知及持续交互 HUD。
6. 验证普通通知仍鼠标穿透，更新提示仍可点击且只执行一次，悬停暂停正确，通知显示/缩放不使 A 失焦；正常淡入淡出与持续状态不变。
7. ChatGPT Ctrl+V 预期仍提示“粘贴受限”；不将其视为本轮新增回归。点击、拖选、复制沿用第五轮路径，真实兼容性继续按第五轮矩阵记录。
