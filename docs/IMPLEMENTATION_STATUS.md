# 实施状态

更新日期：2026-11-11。本页是完成度、验证结果和待完成项的唯一记录入口。[架构](ARCHITECTURE.md)描述当前实现，[实施计划](IMPLEMENTATION_PLAN.md)定义验收操作及预期。实现、自动化通过、用户实测通过分别记录，不以其中一种代替另外两种。

## 阶段总览

| 阶段 / 里程碑 | 实现程度 | 验收与剩余边界 |
| --- | --- | --- |
| Phase 0 / M0 Technical Spike | 实现基线完成，无独立 Spike 工程 | 基本闭环由用户确认；未建立全部窗口/系统环境覆盖。 |
| Phase 1 / M1 Ghost Core | 单窗口闭环、拾取、快捷键、几何和恢复已实现 | 基本闭环、正常退出恢复通过；目标关闭能清理，但错误提示待核查。 |
| Phase 2 / M2 Reliability | Watchdog v1、身份校验、稳定恢复已实现；其他可靠性工作未全部完成 | Watchdog 真实恢复通过；动态缩放存在明确缺陷，跨权限反馈不完善；多屏、长时间资源和系统会话结束未完成验收。 |
| Phase 3 / M3 Productization | 设置/配置、HUD、单实例、导出、更新和签名 NSIS 链路已实现 | 常用设置、通知、安装/覆盖/卸载及应用内更新获用户确认；干净环境及专项失败场景仍待测，Authenticode 未实现。 |
| Phase 4 / M4 Advanced Rendering | Composition 羽化/模糊、硬边回退、缓存及最高 120 Hz 自适应调度已实现 | 日常视觉与流畅度无明显问题；定量性能、设备异常和混合 DPI 未验收。 |
| 实验性后台交互 | 默认关闭；持续/手动会话、控件路径和输入清理已实现 | 部分可用，未达到通用兼容目标；三个用户场景结果见下表，后续转为通用机制可行性研究。 |

阶段实现完成不等于全部验收门槛已关闭；M2/M3 的完整验收仍未完成。具体类型、配置和协议由源码及架构文档维护，不在此复制功能清单。

- 历史基线：2026-11-02 第七轮报告记载 Release 352 项通过（Core 172 / App 180）、元数据检查及图标状态/缩放渲染检查通过。原始 TRX、JSONL、`validation.json` 当时存于 `artifacts/background-interaction-round7/`；产物不随 Git 提交，此处保留的是历史记录，未重新认定可复现。

| 干净安装与运行时 | 只有本机安装/覆盖/卸载反馈 | Win10/11 隔离环境验证无/x86-only/仅高版本 .NET、快捷方式、中文空格路径、旧 MSI 拒绝与卸载保留数据。 |
| 更新失败与性能 | 尚无真实身份/进程残留、包体占用、中断回退、启动失败及各十次耗时 | 按安装矩阵验证失败不改旧程序、不强杀；记录安装/更新阶段耗时。 |
| 配套功能及故障反馈 | 开机启动、单实例、导出、损坏配置、保存失败/热键冲突未逐项确认 | 使用隔离配置与测试目录，按功能矩阵核对实际结果，分别补验收。 |
| 注销/关机 | 用户未测，提前恢复处理也未实现 | 待相应实现完成后，在可取消的会话结束和正常注销/关机中验证尽力恢复。 |
