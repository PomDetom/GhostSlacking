# 安装与更新

- App 默认检查 Stable，主动开启 Test 后才纳入 beta/RC；完整 SemVer 排序。跳过版本只抑制该版本启动通知/托盘入口，“关于”仍允许安装。检查时间与跳过版本写入 `update-state.json`。
- `ApplicationUpdateManager` 持有一个版本/包体/来源固定的下载任务，独立于更新窗口。`IUpdateSource` 提供版本、说明、资产及来源 URL 规则，当前生产实现为 GitHub；`InstallerDownloader` 和持久缓存不依赖 GitHub API。后续来源接入仍须遵守签名和包体身份，不因可替换来源而放宽现有 GitHub URL/重定向边界。
- 更新窗口使用版本信息头、可滚动说明卡与固定操作区。下载或校验时提供暂停和后台执行，显示字节进度、速度和预计剩余时间；“更多”提供停止并清除缓存、发布页及跳过/恢复提醒和重新检查。有未结束任务时禁止重新检查或替换任务，通道设置只影响后续任务。无法自动安装的副本仍通过主按钮前往发布页。
- 普通关闭窗口暂停并保存进度；点击后台下载/更新关闭窗口后继续校验和自动安装。暂停保留缓存，停止等待请求结束后清除该任务缓存；暂停、停止和退出立即撤销旧任务自动安装授权，迟到结果不能安装。退出主程序先保存进度，下次启动恢复为暂停，手动继续才重新授权；已进入安装交接的流程不因关闭窗口撤销。
- 默认文件达到 8 MiB 后按 2 MiB 分段、至多 4 路并发，较小文件单流；验证 Range、Content-Range、长度及强 ETag，有强 ETag 时发送 If-Range。无 Range 支持降级单流；无法续传时保留缓存并明确提供重新下载。网络临时失败最多重试三次，指数退避并尊重 Retry-After；连接、响应头与读取无进展分别有超时，流式下载不受固定总时长限制。
- 分段会在当前下载会话内复用已通过来源规则验证的 CDN 地址，403/401 时有界地重新解析规范资产地址；临时授权 URL 不写入缓存，暂停后的新会话重新解析，来源规则仍约束每次重定向。
- `updates/<version>/download.json` 保存签名发布身份、来源、必要校验材料、各段已落盘位置及摘要；先刷新分段数据再原子保存索引，异常退出从最近有效检查点恢复，损坏分段重新获取。完整包复用前重验签名、长度和 SHA256，补齐原安装交接所需文件后使用原安装包路径。启动保留一个未完成任务及最近一个完整包，非活动缓存按 30 天及当前版本清理；仅删除已知下载文件，保留 Updater 暂存、备份与锁定文件，不再无条件删除 `.partial`。
- 旧 MSI-only Release 与无效签名包、网络错误分开处理。标签、清单、EXE 名称/大小、SHA256 相互核对；下载先写 `.partial`。固定公钥 ECDSA P-256/SHA256 验证格式 2 清单；发布签名不同于尚未实现的 Windows Authenticode。
- 仅 HKCU 注册路径匹配、NSIS 协议 2 且未提权的安装副本提供自动安装；其他副本打开 Releases。Updater 再验清单与包体，并在安装期间保持禁止写入/删除的包体锁。
- Ready/Go 两阶段交接授权后才关闭 App。原生安装辅助程序验证管道服务端可执行路径、PID/启动时间，等待 App 恢复目标及 Watchdog 退出后收到 SAFE；身份不符、恢复失败、残留进程或 30 秒超时均停止，不强杀 App/Watchdog。
- Updater 等待安全退出，显示 NSIS 被动进度，安装后重启；失败/取消尝试重启旧应用。成功安装须在 15 秒内经当前用户管道确认新 PID、会话和实际版本，保存一次性结果并回执后才消费结果/清理备份。
- 原生辅助程序独立于 .NET，负责 x64 .NET 8 检测、旧 MSI UpgradeCode 检测、目录互斥、暂存解包、事务回退及中断恢复。安装目录归属通过 `installation.ini` 确认；拒绝不安全目录、降级及自动 MSI 迁移。新版本确认前保留备份，替换阶段禁止取消。
- 安装为当前用户 NSIS EXE；用户数据独立于程序目录。卸载器也携带原生辅助程序，卸载不依赖 .NET，保留设置与日志。构建、密钥和版本规则只维护在[发布流程](../development/RELEASE.md)中。
