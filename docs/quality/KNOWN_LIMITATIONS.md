# 当前限制与未验证范围

本页维护仍影响开发或使用决策的缺陷、能力缺口及验收边界。架构说明“已实现”不等于兼容性通过。当前实现见[架构入口](../architecture/OVERVIEW.md)，操作与预期见[手工矩阵](WINDOWS_MANUAL_MATRIX.md)。逐次验证结果保存在对应 PR 和构建产物中，不在此累计。

## 现有用户反馈的证据范围

以下反馈来自维护者的单屏使用；未完整提供 GS 提交、目标程序版本、系统版本或完整操作记录。它们只支持所述场景，不代表 Windows 10/11、所有窗口类型或混合 DPI 通过。

- 普通模式基本闭环、正常退出恢复、常用设置保存/取消/重启、普通 HUD、当前用户 EXE 安装/覆盖/卸载和一次应用内更新曾获确认；专项失败条件仍见下方缺口。
- Watchdog 在只结束主进程、保留 Watchdog 的场景曾恢复成功；缩放后异常恢复和完整窗口状态覆盖仍待验收。
- 动态缩放曾出现隐藏闪烁；最大化 Chrome 从 125% 到 100% 后还曾恢复误报、托盘恢复状态残留。几何过渡与最大化恢复已修正，维护者确认该反馈场景复测无异常。不能据此关闭完整 DPI、Watchdog 或多屏矩阵。
- 日常羽化、模糊和流畅度未见明显问题，但没有定量性能、长时间资源或设备异常验收。
- 实验输入结束曾未见卡键，但缺少前台 A 的完整焦点事件记录。

## 实验交互实际兼容性

| 场景 | 反馈 | 边界 |
| --- | --- | --- |
| Notepad++ | 相对可用，结束无卡键 | 具体操作未逐项确认，严格焦点验收未完成。 |
| ChatGPT（客户端/网页形态未提供） | 可查看，不能操作 | 当前交互不可用；隔离 UIA 试验不能推翻该反馈。 |
| Chrome | 操作即收起 Reveal | 当前交互不可用；失焦、投递失败或其他保护原因尚未确定。 |

UIA、Edit、MSAA、隔离 Chromium 和中文 TSF/小词表工具均为独立研究。控件试验、成功返回、可编译和采样焦点相同不证明真实目标、可见 Reveal 或全程焦点通过。工具操作及安全边界分别见[交互探测](../../tools/BackgroundInteractionProbe/README.md)和[中文原型](../../tools/BackgroundImeProbe/README.md)。

## 已知缺陷与待核查反馈

| 优先级 / 项目 | 证据与复现 | 下一步与完成条件 |
| --- | --- | --- |
| 动态缩放反馈场景已修复，扩展兼容性待验收 | 历史存在隐藏切换闪烁；追加 125% → 100% 后恢复误报和托盘状态残留。维护者在追加修正后确认复测无异常 | 上述反馈场景已关闭；继续按矩阵记录各系统/目标版本、双向缩放、普通/最大化、退出及 Watchdog 异常恢复，不将单一场景通过扩展为全部 DPI 兼容性通过。 |
| 中：跨权限无可见反馈 | 普通 GS 选择管理员目标无反应；提权后能选中，尚未查日志 | 定位拾取/捕获/拒绝阶段，提供明确反馈并确认失败前目标未被修改；不将默认提权作为解决方案。 |
| 待核查：目标关闭提示 | 用户关闭受控目标后出现“显示未成功”，最终清理为未选中 | 区分关闭竞态与真实 Reveal 失败；正常关闭应清理且提示准确，不误操作复用 HWND。 |
| 高：实验交互不满足目标 | ChatGPT 无法操作，Chrome 一操作即收起，Notepad++ 仅部分证据 | 作为通用机制研究输入，保留可复现案例与完整日志；不默认追加按应用适配任务。当前代码及默认关闭入口保留。 |

| 项目 | 当前证据 / 边界 | 下一步与完成条件 |
| --- | --- | --- |
| 系统会话结束前尽力恢复 | 源码未处理 `WM_QUERYENDSESSION` / `WM_ENDSESSION`；异常恢复依赖 Watchdog | 设计会话结束/取消路径并补测试；仅恢复仍存活且身份匹配的目标，不持久化旧 HWND，不承诺强制关机一定恢复。 |
| 完整性级别诊断 | 尚无目标完整性级别识别，用户见跨权限无反馈 | 与上表权限问题一起设计诊断及清楚的失败提示。 |

| 通用后台交互机制 | 用户目标是兼容各类程序；当前依赖控件暴露能力，实际兼容性差距明确 | 后续独立研究通用输入/焦点机制及可行边界；先以跨技术栈操作和 A 全程焦点/结束清理作为验证门槛，不能以增加某个应用特例宣布目标达成。研究与重写须作为独立需求实施。 |

## 未验证范围

| 场景 | 当前缺口 / 原因 | 下一步 / 完成条件 |
| --- | --- | --- |
| Windows 10 与目标窗口类型 | 未提供 Win10、Explorer/Electron/自绘等逐项记录 | 在相应系统记录每类窗口的完整闭环，不能从单个应用推广。 |
| 多屏、混合 DPI、负坐标、热插拔/刷新率变化 | 用户无多屏环境；单屏上述缩放反馈场景已复测通过，完整 DPI 矩阵仍未覆盖 | 有设备后逐项验证几何、定位、刷新率更新和恢复；条件不足持续保留未验证。 |
| 长时间与定量性能 | 仅日常流畅度反馈，没有计时资源数据 | 按 30 分钟 Idle/Ghost、10 分钟 Reveal、2 小时资源矩阵记录 CPU/内存/句柄及帧耗时，无持续增长。 |
| Composition 异常 | 无 RDP、透明关闭、设备丢失真实记录 | 分别验证硬边回退、可交互和恢复；无法复现设备丢失时保留限制。 |
| 实验操作与全程焦点 | 具体操作覆盖未细分，没有浏览器 A 完整记录 | 按后台矩阵记录 B 结果、A 事件、系统前台、结束清理及时间区间；失败项不得记通过。 |
| 应用内更新与通知 | 常规更新正常，Ghost/Peek 交接和通知点击/悬停未确认 | 在无敏感测试目标中分别验证恢复、退出顺序、点击一次和悬停暂停。 |
| 干净安装与运行时 | 只有既有使用环境安装/覆盖/卸载反馈 | Win10/11 隔离环境验证无/x86-only/仅高版本 .NET、快捷方式、中文空格路径、旧 MSI 拒绝与卸载保留数据。 |
| 更新失败与性能 | 尚无真实身份/进程残留、包体占用、中断回退、启动失败及各十次耗时 | 按安装矩阵验证失败不改旧程序、不强杀；记录安装/更新阶段耗时。 |
| 配套功能及故障反馈 | 开机启动、单实例、导出、损坏配置、保存失败/热键冲突未逐项确认 | 使用隔离配置与测试目录，按功能矩阵核对实际结果，分别补验收。 |
| 注销/关机 | 用户未测，提前恢复处理也未实现 | 待相应实现完成后，在可取消的会话结束和正常注销/关机中验证尽力恢复。 |
