# Windows 液态玻璃交互样板

在 Windows x64 上安装 .NET 8 桌面运行时和可构建本仓库的 SDK，双击 [Preview.cmd](Preview.cmd)。也可以从仓库根目录运行 `dotnet run --project tools/LiquidGlassSample -c Release`。关闭带工具栏的背景窗口即可结束整个样板。

## 三步体验

1. **设置页面**。初始窗口使用正式应用的六个设置页面。先点背景窗口工具栏的「暂停背景」，再切换「折射 · 开 / 关」，观察卡片边缘的等高线。打开一项调整后，观察浮层边缘穿过的设置文字。切换明暗可比较可读性。单项「完成」后用全局「保存」将改动应用于本次样板会话。
2. **通知**。点击「普通通知」后，用鼠标点通知中心，可以从背景窗口的点击计数验证穿透。趁通知可见再次触发可替换文字。「可点击通知」支持悬停暂停与单次点击反馈。设置页调整圆角、宽度、高度和位置并保存后可再试。
3. **Reveal**。点击「Reveal」，将鼠标移入测试背景。观察网格穿过羽化外环时的弯折、中心的清晰度，以及移动/点击时的状态反馈。在显示设置中切换三种形状、羽化宽度、模糊等级和最大帧率。羽化宽度设为零或外环越过测试背景时显示硬边。工具栏显示 Skia 绘制频率和 P95 绘制间隔。

## 像素来源与工作范围

设置外壳、HUD 与 Reveal 从独立背景 HWND 显示的同一幅内存图像取样，按物理屏幕坐标换算至各自的 DIP。靠近弧面边缘的网格顶点改变纹理坐标，软化与高光在关闭折射时仍可对照。设置卡片叠加外壳色调。打开调整浮层后额外渲染下方设置页至内存，浮层以最高 8 Hz 更新这份输入，关闭时释放。图像可在样板内查看，验证输出只记录计数、时序和环境。

样板借用正式应用的设置与通知控件、Reveal 几何、原生环形 region 和帧率策略。入口使用独立 Avalonia 生命周期及内存设置。通知定位以测试背景为工作区，Reveal 的可点击目标也是该背景。跨进程背景采样和正式版材质接入须在样板评审后另行决定。

## 重跑样板验证

从仓库根目录运行 `pwsh -File tools/LiquidGlassSample/Verify.ps1`。脚本复用仓库的隔离桌面运行器，在样板窗口上检查取样对齐、开关折射的像素差异、原生命中和硬边回退，并按 60 和 120 FPS 两个目标记录绘制帧间隔。日志保存在 `artifacts/tools/LiquidGlassSample/`。目标档位与显示器物理刷新率分别记录，绘制计数来自 Skia 调用。正式项目的 Release 测试入口为 `pwsh -File tests/Run-ReleaseTests.ps1`。
